# service-desk-lab
I resolved 19 simulated IT support tickets in Service Desk Simulator. This portfolio highlights selected cases in account provisioning, access management, and troubleshooting.

## Case Studies

- [Customer Support PC Replacement](customer-support-pc-replacement.md) — Set up and sent a replacement desktop after a critical workstation failure in the simulator.
- [New Employee Onboarding](case-studies/new-employee-onboarding.md) — Created a directory account and assigned three requested access groups in Service Desk Simulator.
- [Team Transfer Access Update](case-studies/team-transfer-access.md) — Removed Engineering group access and granted access for the employee’s new IT Infrastructure role in Service Desk Simulator.
- [Third-Floor Network Outage](third-floor-network-outage.md) — Found an offline switch and restored connectivity in the simulator.
- [MFA Sign-In Recovery](mfa-sign-in-recovery.md) — Reset MFA enrollment in the simulator and restored sign-in for a locked-out employee.
