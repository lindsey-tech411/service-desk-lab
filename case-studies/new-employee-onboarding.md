# New Employee Onboarding

**Environment** — Service Desk Simulator  
**Ticket** — INC0012853  
**Status** — Resolved

## Request

A new junior developer in Engineering needed a directory account
and access to team resources, the VPN, and the code repository
before orientation.

## What I checked

I reviewed the account details and the three group memberships
listed in the onboarding request.

## What I did and why

I created the account in the simulator's Directory using the name
and username provided in the ticket. I added the account to the
three requested groups:

- `Engineering` for team resources
- `VPN-Users` for VPN access
- `CodeRepo-Access` for code repository access

## Outcome

The simulator marked the ticket as Resolved after I completed
the account setup and group assignments.
